# Security

Turnback runs inside coding agents' hooks and stores copies of project files, including gitignored ones such as `.env`, under `~/.turnback`. Reports about anything that could leak those copies, write outside the workspace, or run commands are welcome.

Please report privately through [GitHub security advisories](https://github.com/MFaizR77/turnback/security/advisories/new) rather than a public issue. You should get a reply within a week.

Only the latest release receives fixes.
